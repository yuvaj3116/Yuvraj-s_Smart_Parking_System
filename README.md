🚗 Smart Parking System (Java OOP Project) 

📌 Overview -

This is a console-based Smart Parking System implemented in Java using Object-Oriented Programming (OOP) principles.
The system helps manage parking slots, track vehicles, and calculate parking charges based on the time duration.

This project demonstrates practical usage of OOP concepts (classes, objects, constructors, encapsulation) while solving a real-world problem.

✨ Features -

✅ Add vehicles and assign them to available slots

✅ Track occupied and free slots in real-time

✅ Record vehicle entry and exit time

✅ Automatic payment calculation:

₹50 for the first 3 hours

₹15 for each additional hour after 3 hrs

✅ Display current parking slot status

✅ Simple menu-driven interface

🛠️ Tech Stack -

Language: Java

Paradigm: Object-Oriented Programming (OOP)

Concepts Used: Classes, Objects, Constructors, Arrays, Encapsulation
